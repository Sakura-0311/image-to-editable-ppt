# Route 4：视觉逆向重建（图片 / PDF / 扁平 PPT/PPTX 转可编辑 `.pptx`）
 
当用户提供幻灯片截图、PNG/JPG 图片、PDF 讲义或图片版 PPT/PPTX 要求还原为可编辑演示文稿时执行本流程。字体、缩放与验收规范严格遵循 `references/de-ai-pptx-v3.1.md`（最终交付格式强制为最新现代 `.pptx`，禁止降级导出老旧 `.ppt`）。
 
## 1. 页面归一化
 
- PDF 输入：使用 `pdftoppm -png -r 150` 逐页渲染为高分辨率 PNG。
- 图片版 `.ppt` / `.pptx` 输入：若为 `.ppt` 先用 `soffice --headless --convert-to pptx` 转为 `.pptx`，提取并保存每页原有演讲备注（原样保留不改写），再转 PDF 后用 `pdftoppm` 渲染为 PNG。
- 记录每页像素尺寸与画幅比例（默认 16:9 `13.333" x 7.5"`，除非源图明显为 4:3 或其他比例）。
 
## 2. 分层解析与并行派发
 
- 1-3 页直接目视解析；4 页及以上按页拆分批次元，派发并行子任务提取结构化版面 JSON。
- 每页在归一化 `0.0-1.0` 坐标系中盘点四层对象：
  1. 背景（纯色、渐变近似或干净背景图）
  2. 原生形状（卡片、圆角矩形、分隔线、箭头、徽章等简单几何）
  3. 可编辑文本框与原生表格（精确文本、层级、预估字号、十六进制颜色、对齐方式与坐标框）
  4. 复杂视觉资产（照片、Logo、插画、复杂图表或无法用原生形状表达的自定义图标）
 
## 3. 资产剥离与底图清理
 
- 使用 Pillow 按坐标裁切照片、Logo 与复杂插画为独立 PNG。
- 若前景文字压在照片或复杂背景上，先清理底层重叠文字再贴图，避免可编辑文本框下方出现重影。
- 严禁把未经处理的整页原图直接当成背景再糊上透明文本框。
 
## 4. 原生重建、渲染质检与现代 `.pptx` 交付
 
- 使用 `python-pptx` 将归一化坐标映射为英寸：用 `add_textbox`（`word_wrap = True`，中文字体优先微软雅黑或思源黑体、三槽字体同写、固定缩放 `92%`）、`add_shape`、`add_table` 和 `add_picture` 重建每一页，并写回原有演讲备注。
- 重建后执行渲染质检：用 `soffice --headless --convert-to pdf` 转 PDF 再用 `pdftoppm -png -r 150` 渲染 PNG，与源图并排对比溢出、缺字、错位与可编辑性，修正至通过后直接交付现代 `.pptx` 文件。

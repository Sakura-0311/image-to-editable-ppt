# `frontend-slides` 动效与 HTML 网页幻灯片扩展规范
 
本规范整合自开源项目 `zarazhangrui/frontend-slides`，用于补充两项能力：
1. 在 `grill-me` 过程中结构化询问用户对**动态效果**的需求；
2. 当用户希望在 `.ppt` 中为特定页加动效，或需要高动效单文件 HTML 网页幻灯片时，提供可落地的节奏与视觉规范。
 
## 1. `grill-me` 必问：动态效果决策题模板
 
在每一轮 `grill-me` 提问中，必须包含如下关于动态效果的决策题（若尚未明确）：
 
```markdown
Q - 动态效果与范围：这份演示文稿是否需要加入动态效果？如果需要，是只加在关键页（封面、章节过渡页、核心结论/大图页），还是全篇每页都加？
- 推荐答案：仅在封面、章节页与核心数据/大图页加入克制的“入场渐显 + 错落揭示”（200-300ms 商务节奏）；信息密集页保持静态，避免干扰阅读。
- 理由：只在重点页加动效能突出叙事节奏且不影响信息密度；全篇都加容易拖慢汇报节奏或造成阅读疲劳。
```
 
### 交付后的固定提示（当用户选择“暂不需要动态效果”时）
 
如果用户在 `grill-me` 中选择**当前不需要动态效果**，在最终交付 `.ppt` 文件时，必须在回复中明确附上以下说明：
 
> 当前版本未添加动态效果；如果你后续希望为其中某几页（例如封面、章节过渡页或重点数据页）或全部页面增加动态效果，直接告诉我具体页码和想要的节奏风格，我可以随时为你补充（也支持导出带完整 CSS 动效的独立 HTML 网页版）。
 
## 2. 情绪-动效匹配表（Effect-to-Feeling Guide）
 
| 氛围目标 | 推荐动效节奏 | 适用视觉线索 |
| :--- | :--- | :--- |
| **商务 / 专业（Professional）** | 克制快速（200-300ms）、干脆平滑入场 | 深蓝/石板灰、精确间距、数据图表主导 |
| **杂志 / 编辑感（Editorial）** | 错落文字揭示（staggered `animation-delay`）、图文交错浮现 | 强字号对比、引文块、衬线标题 + 无衬线正文 |
| **电影感 / 强冲击（Dramatic）** | 慢速淡入（1-1.5s）、0.9 -> 1.0 缩放过渡、视差 | 深色底、聚光氛围、全幅大图 |
| **极简 / 克制（Calm）** | 极缓微弱渐显、轻柔淡出 | 高留白、低饱和配色、大内边距 |
| **科技 / 未来感（Techy）** | 网格揭示、微光高亮、打字/数据跳动 | 网格底纹、等宽数字、高对比强调色 |
 
- **`.ppt` 落地原则**：遵循 `de-ai-pptx-v3.1.md` 第十二章规则——**只在字少图大的重点页加动效**，去掉动画后页面核心信息不得受损。
 
## 3. 单文件 HTML 网页幻灯片选项（仅当用户明确要求网页版/高交互动效时）
 
如果用户要求生成可在浏览器直接演示的高动效 HTML 网页版（而非 `.ppt`）：
1. **零依赖单文件**：全部 CSS/JS 内联，无需 `npm` 或构建工具。
2. **固定 16:9 舞台（`1920x1080`）**：整体等比缩放适配视口，禁止在手机端重排内部版式；通过 `.active` / `.visible` 的 `visibility`、`opacity` 和 `pointer-events` 控制切页（禁止用 `display: none/block` 覆盖 flex 布局）。
3. **必备细节**：支持 `prefers-reduced-motion` 无障碍降级、键盘左右键/空格翻页、以及浏览器内联文本编辑快捷键（如 `E` 键）。
